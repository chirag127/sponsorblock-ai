SponsorBlock AI

ML-powered sponsor segment detection and automatic SponsorBlock submission for YouTube videos

GitHub MIT License SponsorBlock API

What it does

Transcript Analysis

Fetches YouTube transcripts and runs ML classifier to detect sponsor/intro/outro segments.

ML Classifier

Trained model identifies sponsored content, self-promotion, interaction reminders, and intros/outros.

Silence Detection

Audio-based silence detection refines segment boundaries for precise timestamps.

Auto Submission

Submits detected segments directly to the SponsorBlock API under your user ID.

Quick start

git clone https://github.com/chirag127/sponsorblock-ai
cd sponsorblock-ai
pip install -r requirements.txt
cp .env.example .env
# Add keys to .env
python -m sponsorblock_ai.cli.main

Environment variables

OPENAI_API_KEY=...          # OpenAI API key (GPT classification)
YOUTUBE_API_KEY=...        # YouTube Data API v3 key
SPONSORBLOCK_USER_ID=...   # Your SponsorBlock user ID
